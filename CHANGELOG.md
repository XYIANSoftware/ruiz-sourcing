# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-12-19

### Added
- Initial project setup with Next.js 15+ and TypeScript
- PrimeReact and PrimeFlex integration with Dark Amber theme
- Project structure with modular components architecture
- Component-specific SCSS styles with glossy, professional design
- Navigation constants and TypeScript interfaces
- Layout components: Navbar (sticky, professional design), Footer, Container
- Common components: Button with glossy effects and smooth animations
- Home page with centered hero section and call-to-action
- About page with professional, Instagram-like info chunks design
- Contact page with welcoming design and social media links
- Mobile-first responsive design using PrimeFlex utility classes
- Barrel exports for clean component imports
- Smooth transitions and animations throughout the application

### Fixed
- Removed deprecated `appDir` from Next.js config
- Fixed ESLint configuration compatibility
- Fixed unescaped apostrophes in About page
- Converted Home page to client component for interactivity
- Improved PrimeFlex integration and responsive design
- Fixed button centering and overall layout issues

### Styling Improvements
- Replaced global styles with component-specific SCSS files
- Added glossy, professional UI with backdrop filters and shadows
- Implemented smooth animations and hover effects
- Used professional Inter font with proper weights
- Created Instagram-like info chunks for better content retention
- Added proper spacing and professional navigation design
- Implemented smooth transitions and micro-interactions

### Technical Details
- Next.js 15+ with App Router
- TypeScript configuration with path aliases
- ESLint configuration for Next.js and TypeScript
- SASS support with component-specific stylesheets
- PrimeReact components with custom styling
- PrimeFlex utility classes for responsive layout
- Dark Amber theme applied globally
- Professional font (Inter) with multiple weights
